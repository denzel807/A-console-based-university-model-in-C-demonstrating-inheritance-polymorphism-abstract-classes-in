# University Management Model

Консольное приложение на C#, моделирующее работу университета и демонстрирующее основные принципы объектно-ориентированного программирования.

В программе представлены различные участники образовательного процесса: студенты, преподаватели, библиотекари и сотрудники охраны. Также реализованы университетские аудитории — компьютерный класс и лекционная аудитория.

## Реализованные возможности

- добавление студентов и сотрудников в университет;
- моделирование начала и окончания учебного дня;
- открытие и закрытие университетских аудиторий;
- вывод информации о студентах, сотрудниках и помещениях;
- расчет возраста и стажа;
- распределение студентов по учебной группе с проверкой максимальной вместимости;
- моделирование работы с документами;
- проведение учебной эвакуации;
- моделирование мероприятий в честь юбилея университета;
- обработка событий с помощью делегатов и событий C#;
- реакция на завершение пары;
- уведомление при переполнении учебной группы;
- обработка изменения даты рождения студента.

- полиморфизм;

- события.

### Основные классы

- `University` — объединяет людей и аудитории и управляет работой университета;
- `Person` — абстрактный базовый класс для людей;
- `Student` — студент;
- `Teacher` — преподаватель;
- `Librarian` — библиотекарь;
- `Security` — сотрудник охраны;
- `Room` — абстрактный класс помещения;
- `ComputerClass` — компьютерный класс;
- `LectureHall` — лекционная аудитория;
- `Group` — учебная группа с ограничением вместимости;
- `Logger` — обработка и вывод сообщений событий;
- `Parents` — пример подписчика на событие завершения пары.

### Интерфейсы

- `IDocumentable` — работа с документами;
- `IEvacuatable` — действия при эвакуации;
- `IPerformable` — участие в мероприятиях.
